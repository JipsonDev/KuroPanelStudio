# KuroPanel Studio @VERSION@

## Orden de lectura manga

- YOLO ordena de derecha a izquierda las cajas que comparten una fila, incluso cuando los globos están a distinta altura.
- Activa **Procesar → OCR → Lectura y portapapeles → Lectura manga · derecha → izquierda** para aplicar la dirección a todo el capítulo. El proyecto guarda la elección.
- El lienzo, el guion, el texto copiado, el OCR y la traducción siguen el mismo orden. Cambiar la dirección renumera las cajas existentes y conserva el texto de cada una.
- Funciona tanto en la detección de la página actual como en la detección del capítulo.

Descarga `KuroPanelStudio-Setup-@VERSION@-Windows-x64.exe` y verifica `SHA256SUMS.txt`.
