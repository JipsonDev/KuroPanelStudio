# KuroPanel Studio @VERSION@ — instalador local

Ejecuta `KuroPanelStudio-Setup-@VERSION@-Windows-x64.exe` para instalar la versión local. El instalador usa la carpeta del usuario y no necesita permisos de administrador.

Esta compilación no se publicó en GitHub. El instalador queda registrado como actualización local para versiones anteriores que ya admiten esta función. Las versiones 0.2.3 y anteriores necesitan ejecutar el instalador manualmente una vez.

Para verificar el archivo, calcula su SHA-256 con `Get-FileHash` y compáralo con `SHA256SUMS.txt`.
